# Course Usage Policy

## Private Materials

Course books, PDFs, EPUBs, DJVU files, and private notes are reference material only. They must not be committed, copied into the repo, uploaded to GitHub, or required for the app to run.

Ignored private material patterns:

- `*.pdf`
- `*.epub`
- `*.djvu`
- `private-course-materials/`
- `course-books/`
- `.codex-private/`

## Allowed Repo Content

The repo may include:

- code
- tests
- generated project-specific summaries
- implementation instructions
- learning roadmaps
- short explanations written in original words

## Copyright And Quoting Rules

Do not quote long passages from private course materials. If a concept is relevant, summarize it briefly in original language and connect it to a concrete project decision.

## How To Use Course Concepts

Use course concepts when they improve the recommendation platform:

- better data collection
- clearer feature engineering
- better evaluation metrics
- more defensible model comparison
- improved recommendation quality

Do not add statistics or ML concepts just to show that they were learned.
